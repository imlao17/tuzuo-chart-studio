### 本轮修复清单

1. **气泡图空白预览（`a98f4ba`）**——示例数据缺 `roleDefaults.size`，且 X/Y 解析分支只组装 `[x, y]` 两列，"需要 3 个数值列"校验在模板自己的示例上必挂，图表根被 `display:none`，用户选气泡图只看到空白。三处修复：示例补 size 默认列；解析器在声明 size 角色且有第三数值列时并入 `seriesColumns`；size/颜色/形状角色下拉对气泡图开放。
2. **桑基/冲积退化数据崩溃（`bb78974`）**——`columnIndex` 对缺失表头回退第 0 列，来源/去向绑定失效时两者落到同列产生 A→A 自环，ECharts 以 "Sankey is a DAG … has cycle" 中止 `setOption`（单列表格切桑基图可复现）。两处渲染器跳过自环行。
3. **回归网加固（`13faab8`）**——上述两类问题分别由标签三态套件与极端数据套件锁定，后续回归可直接捕获。

### 遗留事项

- **浏览器自动化稳定性**：本轮 IAB 标签页两次被整体回收（页面回到 about:blank），靠页面驻留状态机 + localStorage 断点续扫完成全量扫描；后续夜间任务的浏览器段落建议沿用该模式并保持小批次（≤8 模板/次）。
