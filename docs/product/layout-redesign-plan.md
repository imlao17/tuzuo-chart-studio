# 页面布局调整方案

更新日期：2026-07-29

## 已确认方向

下一版先采用“左侧基础栏，右侧调参栏”的布局逻辑。

执行状态：第一版已落地。左侧已改为模板、内容、画布基础信息；标题对齐归入内容区；右侧已把数据字段前置；四周边距已归入左侧画布区并标明 `px`。

本次补充：数据标签已增加文字颜色和更细的位置选择，右侧标签区不再只用“内部 / 外侧”粗粒度表达；图例位置已参与图表区留白计算，并新增对齐控制，顶部/底部可选靠左、居中、靠右，左右侧可选靠上、居中、靠下。

核心判断：

- 左边管这张图的基本身份和页面骨架；
- 中间保持最大预览和数据表工作区；
- 右边管做图过程中需要频繁试、频繁改的部分。

这比简单按“数据 / 样式”切分更贴近真实工作流：用户先确定图是什么、叫什么、多大，再不断调整字段、颜色、标签、轴和图形细节。

## 左侧：基础栏

左侧负责低频但基础的项目设定。

建议放：

1. 图表模板
2. 标题
3. 副标题
4. 来源 / 注释（后续可加）
5. 标题对齐
6. 页面尺寸：编辑当前画布宽度、高度，并标明单位 `px`
7. 背景：透明背景、背景色

左侧不建议放：

- 大量滑杆；
- 系列字段勾选；
- 颜色逐项编辑；
- 坐标轴细节；
- 模板专属高级参数。

原因：左侧应该稳定、安静，像“这张图的基本档案”。用户不应该在左侧进行大量反复调参。

## 中间：结果工作区

中间继续负责主要工作结果。

建议保留：

1. 图表预览
2. 透明背景棋盘格
3. 当前画布尺寸和缩放比例
4. 预览 / 数据表切换
5. 数据表编辑模式

中间不建议塞表单控件，避免削弱“看图”的主任务。

## 右侧：调参栏

右侧负责高频修改项，也就是用户会边看预览边反复调整的部分。

建议优先顺序：

1. 数据字段 / 系列选择
2. 配色
3. 标签
4. 图例
5. 当前模板的图形设置
6. 坐标轴
7. 数字格式
8. 高级项：参考线、参考区间、双轴、阈值等

右侧应该支持搜索，但搜索结果最好不仅打开设置组，也能让命中的具体控件更容易被看见。

## 顶部：全局操作

顶部只保留跨页面、跨模式的全局操作。

建议放：

- 预览 / 数据
- 打开项目
- 保存项目
- PNG 倍率
- 复制 PNG
- 下载 SVG
- 下载 PNG

顶部不再继续塞样式设置。

## 新版三栏结构

### 左侧

基础信息：

1. 模板
2. 标题 / 副标题 / 来源 / 标题对齐
3. 画布尺寸：宽高输入，标签标明 `px`
4. 背景

### 中间

主工作区：

1. 预览
2. 数据表

### 右侧

高频调参：

1. 数据字段
2. 快速样式
3. 图形细节
4. 坐标和数字
5. 高级设置

## 第一版改法

第一步：把“画布与布局”里的高频/基础项拆开。

- 标题对齐移动到内容区，跟标题、副标题放在一起；
- 宽度、高度、透明背景、背景色移动到左侧画布区，宽高输入标签标明 `px`；
- 四周边距移动到左侧画布区，并标明单位 `px`，作为画布基础信息的一部分。

第二步：把“数据字段”从左侧移动到右侧靠前位置。

- 字段绑定；
- 系列选择；
- 组合图柱/线切换；
- 散点图 size/color/shape；
- 当前数据不适合模板时的提示。

第三步：右侧设置按频率重排。

建议顺序：

1. 数据字段
2. 配色
3. 标签
4. 图形
5. 图例
6. 坐标轴
7. 数字格式
8. 高级布局

第四步：按模板动态精简右侧。

例如：

- 饼图：隐藏坐标轴，突出扇区、标签、图例；
- 条形图：把轴命名成分类轴 / 数值轴；
- 散点图：突出 X/Y 字段和点编码；
- 组合图：突出系列类型和双轴；
- 河流图：突出时间轴和面积透明度。

## 暂不做

- 暂不做完整移动端重构；
- 暂不做发布、嵌入、故事系统；
- 暂不把所有设置塞到左侧；
- 暂不新增大量模板；
- 暂不做复杂多页面设置向导。

当前最重要的是把现有单页编辑器变得更顺手：左边定基本盘，右边快速调图，中间一直看结果。
