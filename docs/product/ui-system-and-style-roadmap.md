# UI 规范与样式增强路线

更新日期：2026-08-09

## 当前顺序

这条路线按三个阶段推进：

1. UI 规范化
2. 图表文字样式增强
3. 账号与云同步

当前状态：

- UI 规范化：已完成第一版；
- 图表文字样式增强：已完成第一版；
- 账号与云同步：已完成邮箱账号和登录后导出的最小闭环，云端项目保存仍未实施。

账号和云同步仍然按“本地优先”推进。当前已经有账号入口，但默认本地部署不强制登录；公开托管时才建议打开登录后导出。

## 第一阶段：UI 规范化

目标：让同层级控件看起来像同一个产品里的组件。

已建立的基础标准：

- 顶栏高度：`58px`
- 普通控件高度：`34px`
- 紧凑控件高度：`32px`
- 小图标按钮高度：`28px`
- 顶栏分组高度：`36px`
- 面板触发行高度：`44px`
- 普通控件圆角：`4px`
- 普通按钮圆角：`5px`
- 分组圆角：`6px`
- UI 正文字号：`12px`
- 小字号：`11px`
- 辅助说明字号：`10px`
- 极小说明字号：`9px`

当前覆盖范围：

- 顶部全局操作栏；
- 左右侧栏显示 / 隐藏按钮；
- 预览 / 数据切换；
- 打开、保存、复制、导出按钮组；
- 左侧模板、标题、画布尺寸、背景和四周边距；
- 右侧搜索、设置分组、配色、保存配色、颜色编辑、分段控件；
- 模板库搜索和卡片；
- 数据表输入文字；
- Toast 和提示条。

继续扩展 UI 时优先复用 `app/globals.css` 里的基础变量，不再为单个按钮随手写新的高度、圆角和字号。

## 第二阶段：图表文字样式增强

目标：让图表中的文字可以更精细地表达重点，而不是只有统一字号。

第一版已覆盖这些对象：

- 标题；
- 副标题；
- X 轴标题；
- Y 轴标题；
- X 轴刻度文字；
- Y 轴刻度文字；
- 数据标签；

第一版已支持：

- 字号；
- 颜色；
- 粗体；
- 斜体；
- 颜色为空时跟随主题或默认色；
- 保存到 `.tuzuo.json` 项目文件；
- 旧项目文件中的 `fontSize` 和 `labelColor` 自动迁移到数据标签样式。

实现方式：

- 在 `ChartConfig` 中增加结构化文字样式对象；
- UI 上用图标按钮表达粗体、斜体、对齐，避免文字按钮过多；
- 渲染器统一从共享工具读取文字样式，减少每个图表家族重复实现；
- 行为测试覆盖标题、坐标轴和数据标签样式进入 ECharts option。

后续可继续扩展：

- 图例文字样式；
- 轴标题与刻度的显示 / 隐藏细分；
- 数据标签背景、描边和阴影；
- 不同系列的数据标签样式覆盖。

## 第三阶段：账号与云同步

目标：在本地体验稳定后，逐步扩展面向外部用户的账户、云端项目保存和权限能力。

已完成：

- 邮箱注册；
- 邮箱验证；
- 登录会话；
- 登出；
- 登录/注册基础限流；
- 可配置的登录后导出；
- 本地模式默认无需登录。

上线前需要明确：

- 是否继续保留“无需登录即可本地使用”的模式；
- 账号体系用邮箱、第三方登录，还是先用邀请码；
- 项目保存到账号后，是否仍支持 `.tuzuo.json` 本地文件导入 / 导出；
- 图表数据是否加密存储；
- 是否需要团队空间、共享链接和版本历史；
- 云端保存失败时，本地编辑是否仍然可靠。

建议产品节奏：

1. 先保持本地优先。
2. 稳定可选登录和导出权限。
3. 登录后保存“我的知图项目”。
4. 增加项目列表、版本历史和删除恢复。
5. 再考虑共享、团队和发布页。
